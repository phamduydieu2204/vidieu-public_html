# VD License Manager

WordPress plugin for license management and distribution system.

## Version
1.0.0

## Requirements
- WordPress 5.0+
- PHP 7.4+
- MySQL/MariaDB with mysqli extension

## Directory Structure
```
vd-license-manager/
├── vd-license-manager.php          # Main plugin file
├── includes/                       # Core classes
│   └── class-vd-loader.php        # PSR-4 autoloader
├── admin/                          # Admin interface
├── public/                         # Public interface
└── README.md                       # This file
```

## Installation
1. Upload to `/wp-content/plugins/vd-license-manager/`
2. Activate through WordPress admin
3. Configure settings
